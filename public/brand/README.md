# ItemShare artwork

These transparent PNGs preserve the approved rounded lettering and the teal/coral
people passing a gift. The wordmark uses white for Item and light blue for Share
on the site's dark header.

- `mark.png`: people and gift, 152 × 91; displayed 72 CSS pixels wide.
- `wordmark.png`: name only, 320 × 59; displayed 166 CSS pixels wide.
- `logo.png`: combined logo, 480 × 90; suitable for display at 240 × 45.

Keep each image's aspect ratio when resizing. The header deliberately uses the
separate mark and wordmark so the existing subtitle can sit below the name.
The PNG lettering does not depend on fonts installed on the visitor's device.
